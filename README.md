# ИАГ карти — userscripts и помощни инструменти

Малка колекция userscripts и един CLI инструмент около картите на Изпълнителна агенция по горите (ИАГ) — публичния GeoServer на `maps.iag.bg` и портала [kade.si](https://kade.si/).

## Съдържание

| Файл | Какво прави |
|------|-------------|
| [`iag-geoserver-fix.user.js`](iag-geoserver-fix.user.js) | Поправя счупените заявки в MapStore визуализатора на ИАГ. |
| [`kade-iag-info.user.js`](kade-iag-info.user.js) | При клик върху картата на kade.si показва ловен район и горска информация. |
| [`iag-lookup.mjs`](iag-lookup.mjs) | CLI: подаваш GPS координати, връща същата информация в терминала. |

---

## iag-geoserver-fix.user.js

Визуализаторът на `https://maps.iag.bg/mapstore/#/viewer/<id>` зарежда конфигурация, в която слоевете сочат към **вътрешен** GeoServer (`http://172.16.4.132:5088/geoserver/...`), недостъпен отвън. Скриптът пренасочва тези заявки към публичния адрес `https://maps.iag.bg/geoserver/...` (същите пътища и параметри).

Пренаписва адреса на три нива: `fetch`, `XMLHttpRequest` (включително телата на отговорите, за да се поправи конфигурацията преди MapStore да я прочете) и като резервен вариант — `<img>` плочки/легенди.

**Инсталация:** Tampermonkey/Violentmonkey → нов скрипт → постави съдържанието. Важи за `https://maps.iag.bg/*`.

## kade-iag-info.user.js

[kade.si](https://kade.si/) е туристически портал на базата на OpenLayers. Скриптът закача клик-хендлър: при клик взема координатите и праща `GetFeatureInfo` към GeoServer на ИАГ, после показва резултата в изскачаща кутийка на самата точка.

Показва:
- **Лов** — ловен район (`lr`) и ловище (`lovishte`), ако е налично;
- **Гора** — дървесен вид, възраст, наклон.

Кои полета се показват се конфигурира в масива `LAYERS` горе в скрипта. Работи с обикновен `fetch`, защото GeoServer връща `Access-Control-Allow-Origin: *`.

**Инсталация:** Tampermonkey/Violentmonkey → нов скрипт → постави съдържанието. Важи за `https://kade.si/*`.

## iag-lookup.mjs

CLI версия на същото запитване — за бърза проверка от терминала.

```bash
node iag-lookup.mjs <lat> <lon>
# напр.
node iag-lookup.mjs 43.189 25.093
# приема и "lat,lon" (както се копира от Google Maps)
node iag-lookup.mjs "43.189,25.093"
```

Пример за изход:

```
[Лов]
  ЛР "Г.Сливово"
  ловище: Ловище 3
[Гора]
  дървесен вид: Зимен дъб
  възраст: 50 г.
  наклон: 23°
```

Изисква **Node.js 18+** (ползва вградения `fetch`). Без външни зависимости.

### Как се вадят координатите

Слоевете нативно се пазят в EPSG:32635 (UTM 35N), но заявките работят в EPSG:3857, затова скриптът превръща WGS84 (ширина/дължина) в Web Mercator и праща `GetFeatureInfo` с мъничка bbox (±3 м) около точката.
